# 中文提问技巧

> 中文提问有它自己的坑。这篇专门讲中文场景下怎么问得更好。

---

## 一、中文的"意思模糊"问题

中文压缩率高，一句话能有很多种理解。

```
"帮我优化一下这个"          → 优化什么？速度？可读性？成本？
"这个不太行"                → 哪里不行？多不行？
"弄成那种感觉"              → 哪种感觉？
```

**解法：把形容词换成数字或具体标准。**

| ❌ 模糊 | ✅ 具体 |
|---------|---------|
| 优化一下 | 响应时间从 3 秒降到 500ms 内 |
| 长一点 | 800-1000 字 |
| 专业一点 | 去掉口语词，不用感叹号，术语首次出现给英文 |
| 快一点 | 减少到 3 步以内 |

---

## 二、术语：中英混用的坑

AI 训练数据里英文术语更多，中文翻译常有歧义。

```
❌ "用那个什么...令牌桶？限流的东西"
✅ "用 token bucket 算法实现 rate limiting"
```

**要么用准确的英文术语，要么描述清楚行为。** 别用"那个什么"。

---

## 三、明确要求"中文输出"

有时 AI 会用英文回答，或者中英夹杂。

```
✅ 在提示词里加一句：
"全程用中文回答。代码、报错、专有名词保留原文，
其余解释用中文。"
```

---

## 四、"说人话"的正确用法

想让它讲得通俗，别说"讲简单点"（它可能真给你删信息），要具体：

```
❌ "讲简单点"
✅ "用大白话，像跟朋友解释一样。
    每出现一个术语，用一句话打比方解释。
    不要为了简单省略关键信息。"

❌ "再人话一点"
✅ "假设我完全没接触过这个领域。
    先说不懂这个也能明白的直觉，
    再说准确的定义。"
```

---

## 五、中文长任务：分段推进

中文信息密度高，一段话塞太多要求 AI 容易漏。

```
❌ 一次给 500 字的需求，7 个要求

✅ 分三步：
第1条消息："我要做一个 X，先别动手，
           听我说完要求再总结一遍"
第2条消息：列要求
第3条消息："先复述你的理解，我确认后再做"
```

---

## 六、让 AI 帮你"翻译"模糊需求

这是中文用户的杀手锏——先让 AI 把模糊需求变清楚：

```
我下面这句话可能说得不清楚，请帮我：
1. 列出这句话有哪几种可能的理解
2. 每种理解下，你猜我想要什么
3. 问我 2 个问题来区分
4. 然后基于最可能的那一种给出回答

我的需求："帮我做个能自动回消息的东西"
```

**结果：** AI 会问你要回答什么消息、什么平台、多智能——模糊需求瞬间变清晰。

---

## 七、中文反问式学习的正确打开方式

```
我想搞懂 [概念]。
请用中文反问式教我：
- 一次只问 1-2 个问题，等我的回答
- 我的回答有偏差时，先指出偏差再往下
- 全程中文，术语保留英文原词
- 最后总结：3 条结论 + 2 个易错点 + 1 个行动
```

---

## 八、中文场景模板速查

| 场景 | 加这句话 |
|------|---------|
| 要通俗 | "用大白话，每个术语打比方" |
| 要简练 | "不超过 N 字，不说客套话" |
| 要严格 | "只给问题，不要优点" |
| 要结构化 | "用表格/编号列表" |
| 要准确 | "不确定的地方标明'需核实'" |
| 要迭代 | "先给方案框架，我确认后你再展开" |

---

## 一句话总结

> **中文提问的关键：把压缩掉的细节补回来。**
>
> 形容词换数字、术语用准确词、模糊需求先让 AI 帮你澄清。
